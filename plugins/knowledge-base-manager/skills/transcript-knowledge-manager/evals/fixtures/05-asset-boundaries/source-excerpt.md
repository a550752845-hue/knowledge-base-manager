# 合成咨询对话拆解

## [00:00-01:20] 场景

讲者：当咨询对象迟迟不回应时，常见错误是连续追加承诺。这样做把信息量增加了，却没有降低对方判断自己是否适合的成本。

## [01:20-02:10] 逻辑机制

讲者：先公开适用门槛，能让不匹配的人退出，也让匹配的人知道下一步。接着提供两个可撤销选择，比单一催促更容易形成明确反馈。这个机制依赖门槛真实、选择可执行，而且不能隐藏价格或风险条件。

## [02:10-02:24] 精确原话

讲者：“先把门槛说清，再把选择交还给对方。”

## [02:24-03:20] 例子与边界

讲者：比如可以让对方选择“继续了解条件”或“暂时不推进”，而不是声称名额马上消失。这个例子只是来源中的表达，不是经过测试的生产话术，也没有授权把整段用于商业发布。

## [03:20-03:50] 结论

讲者：可复用的是降低判断成本的结构，不是把我的原句换个渠道直接发送。新话术必须根据受众、场景、事实、权限和渠道重新生成并审阅。
