# r01 开场：少打扰的单次提醒

## 1. 问题

合成服务团队发现，预约后连续发送三次相同提醒会让接收者忽略信息。作者起初提出：一次提醒通常已经足够，更多提醒只会增加噪声。

## 2. 初始主张

初始主张的前提是，接收者已经理解预约意味着什么、需要做什么，并且取消入口清晰。在这个前提下，重复同一消息没有新增信息。
