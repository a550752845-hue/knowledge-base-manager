# r04 结论：条件化的两阶段策略

## 7. 合并结论

最终策略不是“一次”或“两次”的固定规则：

- 状态含义清楚、动作单一、退出入口可见时，发送一次包含完整信息的提醒。
- 状态含义不清或需要先补前提时，分成“校准含义”和“请求动作”两个阶段。
- 任一阶段都应提供退出或改期入口；不得用虚假稀缺制造回应。

作者明确表示，这个结论只覆盖合成预约沟通，不证明更多消息在其他行业或高风险场景有效。

## 8. 行动意图

先标记预约的状态不确定性，再选择单阶段或两阶段流程。试点后记录未回应原因，若无法区分“忘记”和“误解”，不得把结果提升为通用规则。
