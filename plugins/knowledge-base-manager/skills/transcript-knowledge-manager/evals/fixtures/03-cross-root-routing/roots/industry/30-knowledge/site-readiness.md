# 温室设备试用前现场准备

预约确认需要同时检查三个合成条件：演示区供电可用、搬运通道未封闭、现场有操作角色。任一条件未确认时，不应继续发送“按时到场”式提醒，而应切换为远程预检并给出新的确认点。

此资产只提供温室设备行业约束，不负责客户成功团队的角色交接。
