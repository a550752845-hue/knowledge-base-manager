# Legacy Operations Manual

Synthetic fixture only. No real people, organizations, or private events are represented.

## 1. Purpose

Provide a fictional handoff pilot procedure.

## 2. Prerequisites

| Requirement | Check |
| --- | --- |
| Stable item ID | ID is unique in the pilot queue |
| Evidence access | Receiving role can open the cited path |

## 3. Procedure

1. Record current state.
2. Attach an evidence path.
3. Record one next action.
4. Assign a role owner, not a personal name.
5. Ask the receiving role to verify evidence access.

If evidence access fails, stop the handoff and route to access repair. Do not copy restricted evidence into a lower-sensitivity folder.

## 4. Output

A handoff record with item ID, state, evidence path, next action, role owner, and access result.

## Appendix A

The sentence “assign an owner” is incomplete when separated from the evidence-access condition.
